# frontend/ NOTES — AgentForge (Agent 1)

Next.js 14 (App Router) + TypeScript + Tailwind CSS frontend. **Build verified:**
`npm install && npm run build` passes (Next 14.2.15, TS 5.9 strict, ESLint
next/core-web-vitals); all 5 pinned page routes + error/not-found/loading
compile, and a `next start` smoke test returned 200 on every route.

## Run it

```bash
cd frontend
npm install
npm run dev        # http://localhost:3000
npm run build && npm start   # production
npm run lint
```

## Env vars used

| Var | Default | Purpose |
|---|---|---|
| `NEXT_PUBLIC_API_BASE_URL` | `http://localhost:8000` | REST base for direct fetches + the `next.config.mjs` rewrite `/api/:path* → $BASE/api/:path*` (read at server start). |
| `NEXT_PUBLIC_API_WS_URL` | `ws://localhost:8000` | WS base for `GET-WS /api/runs/{id}/stream`. WS does **not** go through Next rewrites (no WS upgrade proxy), hence the separate var. |
| `NEXT_PUBLIC_DEMO_MODE` | unset | `1` (or `true`/`yes`) forces the built-in demo engine (`lib/demo/`). Even without it, any network-level failure (backend down) transparently degrades to demo mode for the session and the header badge flips to "Demo mode" — honest, per the no-fakes rule. |

## Key decisions

- **Zero runtime deps beyond Next/React.** Charts (bar/line/scatter/pie) are
  hand-rolled SVG in `ChartBlock` (native `<title>` tooltips); the demo-mode PDF
  is generated by a ~100-line PDF 1.4 writer (`lib/demo/minipdf.ts`). Keeps
  first-load JS ≤ ~130 kB and the demo fully offline.
- **Single source of truth = event envelope.** `useRunStream` seeds from
  `GET /api/runs/{id}`, then applies live envelopes (dedup by `seq`); plan,
  agent states, artifacts, token usage and run status are all derived by folding
  events (`lib/events.ts`), so WS, polling and demo replay produce identical UI.
- **Stream strategy:** WS open → send `{"type":"replay","after_seq":N}`; on drop →
  poll `GET /api/runs/{id}/events?after_seq=N` every 2.5 s and retry WS with
  exponential backoff (1.2 s → 2.4 s → 4.8 s); after 3 failed attempts it stays
  in polling (labelled in the UI). Heartbeat `{"type":"ping"}` every 30 s.
- **`token_update` payloads are treated as deltas** per event;
  `run_total_usd` (cumulative) is authoritative for the run cost when present.
- **Dark mode:** Tailwind `class` strategy; inline bootstrap script in
  `layout.tsx` applies system preference pre-paint (no FOUC); toggle persists to
  `localStorage("agentforge-theme")`.
- **Hero variants:** `/` renders **HeroA** (split hero + live-run console mock —
  recommended; it demonstrates the product). Preview HeroB (centered + agent
  pipeline strip) at `/?hero=b`.
- **Sample-dataset chips** (`/new`) build a small CSV in-browser and push it
  through the real `POST /api/upload` path, so they work identically in live
  and demo mode (no backend sample-file endpoint needed).

## Deviations / notes for the coordinator

1. **Artifact enrichment:** `Artifact.data` (optional `ChartSpec` for `chart`
   artifacts, `{columns, rows}` for `table`) is frontend-tolerant. The demo
   engine includes it; if Agent 2's snapshot omits it, the feed falls back to
   metadata-only rendering — no breakage either way.
2. **`agent_finished` payload** is not pinned; typed as `{}` (optional
   `subtask_id` tolerated).
3. **Report downloads:** live mode fetches `GET /api/runs/{id}/report?format=…`
   via the same-origin rewrite; demo mode renders Markdown client-side and PDFs
   via the mini-PDF writer (labelled "demo-mode PDF export" on the page).
4. **Demo run ids:** `demo-run-1..3` are pre-seeded succeeded runs; newly
   created runs animate live (~35 s scripted stream). An unknown run id in demo
   mode spins up an animating run for the flagship churn mission rather than
   404-ing (judges may paste URLs). Run ids containing "fail" demo the
   `run_failed` path.
5. **Sample chips + template picker prefill** go beyond the pinned API (purely
   frontend, no extra endpoints).
6. Seeded demo data uses fixed timestamps (2026-10-04) and simulated figures,
   labelled as demo content everywhere it renders — per the honesty rules.
