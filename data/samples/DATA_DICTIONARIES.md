# Sample Dataset Data Dictionaries

Machine-readable column documentation for the four AgentForge sample datasets
(parsed at import time by `backend/connectors/samples.py` — keep the
`## sample_id` section headers and the `| column | type | units | description |`
table shape intact).

All CSVs are generated by `scripts/generate_samples.py` (seed 20261005) and are
byte-for-byte reproducible.

## saas_churn

| column | type | units | description |
| --- | --- | --- | --- |
| customer_id | string | - | Unique customer identifier, format CUST-##### |
| signup_date | date | ISO date (YYYY-MM-DD) | Date the customer subscribed (2023-10-01 to 2026-08-31) |
| plan | string | category | Subscription tier: basic, pro, or enterprise |
| monthly_price | float | USD per month | Recurring subscription price at time of snapshot |
| region | string | category | Customer region: north_america, europe, apac, latam |
| months_active | integer | months | Months from signup to churn (churned) or to the 2026-09-30 snapshot (active) |
| logins_last_30d | integer | logins per 30 days | Product logins in the customer's final observed 30-day window |
| tickets_raised | integer | tickets (lifetime) | Total support tickets raised by the customer |
| is_churned | boolean | 0/1 | 1 = cancelled before the 2026-09-30 snapshot, 0 = still subscribed |

## ecommerce_sales

| column | type | units | description |
| --- | --- | --- | --- |
| order_id | string | - | Unique order identifier, format ORD-###### (sequential by date) |
| order_date | date | ISO date (YYYY-MM-DD) | Order date spanning 2025-10-01 to 2026-09-30 |
| product_category | string | category | electronics, apparel, home_kitchen, beauty, sports, or books |
| product_name | string | - | Product display name (6 per category) |
| region | string | category | Shipping region: north_america, europe, apac, latam |
| channel | string | category | Sales channel: web, mobile, or marketplace |
| quantity | integer | units | Number of units in the order (1-5) |
| unit_price | float | USD | Price per unit |
| revenue | float | USD | order total = quantity x unit_price |
| is_returned | boolean | 0/1 | 1 = order was returned |

## support_tickets

| column | type | units | description |
| --- | --- | --- | --- |
| ticket_id | string | - | Unique ticket identifier, format TKT-##### |
| created_date | date | ISO date (YYYY-MM-DD) | Ticket creation date spanning 2025-10-01 to 2026-09-30 |
| category | string | category | billing, login_bug, how_to, feature_request, or integration |
| priority | string | category | low, medium, high, or urgent |
| subject | string | - | Short human-written ticket subject line |
| first_response_hours | float | hours | Hours from ticket creation to first agent response |
| resolution_hours | float | hours | Hours from ticket creation to resolution (populated for all rows; unresolved tickets have elapsed time at snapshot) |
| is_resolved | boolean | 0/1 | 1 = resolved before the 2026-09-30 snapshot |
| csat | integer | 1-5 score | Customer satisfaction rating; EMPTY when is_resolved = 0 (deliberate missing values) |

## marketing_spend

| column | type | units | description |
| --- | --- | --- | --- |
| week_start_date | date | ISO date (YYYY-MM-DD) | Monday of the week; 160 consecutive weeks ending 2026-09-28 |
| channel | string | category | Acquisition channel: search, social, email, content, or referral |
| spend | float | USD per week | Paid + content production spend for the week |
| impressions | integer | impressions | Impressions delivered that week |
| clicks | integer | clicks | Clicks on channel assets that week (always <= impressions) |
| signups | integer | signups | Free-trial signups attributed to the channel that week (always <= clicks) |
| conversions | integer | conversions | Paid conversions that week (always <= signups) |
